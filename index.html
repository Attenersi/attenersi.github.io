.03
Operations Research · Client Project

DKG Logistics Optimisation

Client project for De Keuken Groep. The problem: how to load mixed cargo of heavy and fragile kitchen units into one truck without the bottom layer crushing the top. We tried ML first; it kept producing mathematically tidy answers that ignored physics. So we switched to a heuristic algorithm and built a 3D packing visualisation around it. The deliverable was twofold — a working prototype, and a clear map of approaches that don't solve the constraints. Both useful when the next team picks it up.

.04
LLM & RAG · Solo Build · Open-Source

Atrio

An LLM-backed assistant for facility-management teams. Atrio answers FM questions from grounded building documentation (RAG with cited sources) and turns reported issues into structured tickets — including multi-issue messages that fan out into multiple tickets. The point isn't a smarter chatbot. It's a faster path from "tenant writes a sentence" to "work order in the system."
